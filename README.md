О проекте

Приложение на Python с GUI, которое автоматизирует переименование PDF-файлов с отсканированными накладными.

Как работает:

Рендерит PDF-страницу в изображение (PyMuPDF)

Обрезает область с номером контейнера (OpenCV)

Распознаёт текст через Tesseract OCR

Находит номер по маске ISO 6346

Переименовывает файл в DLRU0036177.pdf

Зачем: ежедневная обработка ~76 файлов вручную занимает 2–3 часа. С программой — 3–5 минут.

 Возможности
 OCR сканированных документов (Tesseract)

 Умная обрезка — обрабатывается только нужная область

 Поддержка разных форматов записи номера (MSKU1234567, MSKU 1234567, MSKU-1234567, MSKU1234567P)

 Многопоточность — GUI не зависает

 Остановка обработки по кнопке

 Защита от дубликатов (_1, _2)
